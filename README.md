A single one-line pickup line, as if a vending machine were flirting, written by `main.ts` to `/output/entry.txt` — nothing else.

## The line

> You don't need coins. Just stand there looking like that and I'll jam on purpose so we can talk.

## Why this line

- **Machine voice:** coins waived, a jam volunteered — the flirt only works inside a vending machine's world.
- **Charming, not creepy:** the machine asks for nothing but presence; the malfunction is offered, not imposed.
- **The punch is the jam:** a vending machine's worst failure reframed as its best move — it breaks itself to keep you there.
- **Fresh angle:** the field saturates with "press B7" and "exact change"; jamming on purpose to keep talking is untouched.
- **Tight:** one clean line, 96 characters against the 200-character gate, short and speakable.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
